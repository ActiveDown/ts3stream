# Инструменты

- `diagnostic-plugin/` — минимальный TS3-плагин для дампа дерева Qt-виджетов.
- `capture-test/` — тест WGC + LiveKit C++ SDK.
- `icon/` — красная иконка LIVE для сервера.
- `serverquery/` — скрипты проверки иконок и UID.

## Проверка передачи с ограниченным битрейтом

Это диагностический запуск для плагина **0.3.9**. В **0.3.10 и новее** используйте поле битрейта в окне «Начать стрим»: явный выбор клиента имеет приоритет над переменной окружения, которую задаёт этот скрипт.

`start-ts3stream-limited.ps1` запускает TeamSpeak 3 с временным потолком битрейта TS3Stream (по умолчанию 4 Мбит/с). Запускать **на компьютере автора трансляции**, предварительно полностью закрыв TeamSpeak. Если стандартный путь не найден, выбрать `ts3client_win64.exe` в диалоге.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-ts3stream-limited.ps1 -MaxMbps 4
```

Это ограничение только для запущенного процесса: плагин, конфиги и постоянные переменные Windows не меняются. В логе автора после начала трансляции должно быть `maxBitrate=4000000`. Для сравнения оставить то же разрешение, FPS и сцену; сопоставить `rtx`, `nack`, `send_queue_ms` у автора и декодирование/зависания у зрителей. Нулевое `lost` в текущей строке `rtc tx` не измеряет потери удалённой стороны — ориентироваться на повторные передачи и подтверждённые входящие пропуски. Вернуться к обычному потолку можно, закрыв TeamSpeak и запустив его обычным ярлыком. `-DryRun -TeamSpeakExe <путь>` проверяет параметры без запуска.
