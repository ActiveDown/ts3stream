# Захват звука

## Требование

Звук обязателен. Нужно выбирать источник:

- при захвате **окна приложения** — звук этого приложения (и, опционально, его дочерних процессов);
- при захвате **экрана** — звук выбранного устройства воспроизведения (системный звук);
- возможность выключить звук.

## Технологии

- **WASAPI process loopback** (Windows 10 2004+) — захват звука конкретного процесса и его дерева.
  - Активация через `ActivateAudioInterfaceAsync` с `AUDIOCLIENT_ACTIVATION_TYPE_PROCESS_LOOPBACK`.
  - `PROCESS_LOOPBACK_MODE_INCLUDE_TARGET_PROCESS_TREE` — захват приложения и его дочерних процессов.
  - `PROCESS_LOOPBACK_MODE_EXCLUDE_TARGET_PROCESS_TREE` — системный звук без дерева процессов TS3.
- **Сырой device loopback не используется для стриминга**: он захватывает TS3 и создаёт петлю.
- Формат: 48 kHz, stereo, 16-bit PCM; SDK кодирует Opus.

## UI

При старте стрима:

1. Выбор источника видео: монитор / окно.
2. Частота кадров: 30 / 60 / Авто (до 60, с адаптацией WebRTC).
3. Выбор источника звука:
   - для окна: «Звук приложения» (по умолчанию), «Системный звук (кроме TeamSpeak)», «Без звука»;
   - для экрана: «Системный звук (кроме TeamSpeak)» или «Без звука».
4. Индикатор уровня звука в панели стрима.

## Ограничения

- Process loopback требует Windows 10 2004+.
- Защищённый контент (DRM) может быть тишиной.
- Некоторые приложения с эксклюзивным WASAPI-режимом могут не попадать в loopback.
- Звук TS3 не захватывается: системный режим использует process loopback с исключением дерева TS3, а при наличии второго `ts3client_win64.exe` helper полностью отключает системный звук (fail closed).
