# Битрейт трансляции на клиенте

В версии **0.3.10** внизу окна **«Начать стрим»**, после выбора звука, есть поле **«Битрейт видео»**:

- диапазон: **1000–10000 Кбит/с**;
- шаг кнопок: **1000 Кбит/с**, доступен ввод с клавиатуры;
- начальное значение: **4000 Кбит/с**;
- применяется к новой трансляции, независимо от разрешения и FPS.

Это верхний предел кодировщика, а не обязательная постоянная скорость и не ограничение суммарного сетевого трафика. WebRTC может снижать скорость при ухудшении канала. Аудио, служебные пакеты и повторные передачи добавляют трафик сверх видеобитрейта; краткие всплески тоже возможны.

Выбор проходит через `CaptureSource` и состояние захвата в `TrackPublishOptions.video_encoding`. Для значения по умолчанию в `diag.log` записываются `bitrate_kbps=4000` и `maxBitrate=4000000`. Явный выбор в окне имеет приоритет над диагностической переменной `TS3STREAM_MAX_BITRATE`; она сохраняется для тестовых программ без явного выбора.

Сервер и установщик для этого выбора не меняются. Выпущенный ранее плагин 0.3.9 ещё не содержит это поле. Само снижение битрейта не гарантирует устранение всех потерь; результаты сетевых тестов следует оценивать отдельно от проверки интерфейса.
