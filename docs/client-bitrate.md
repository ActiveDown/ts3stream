# Битрейт трансляции на клиенте

В версии **0.3.11** внизу окна **«Начать стрим»**, после выбора звука, есть выпадающий список **«Битрейт видео (Кбит/с)»**:

- диапазон: **1000–10000 Кбит/с**;
- варианты списка: **1000, 2000, …, 10000 Кбит/с**, доступен ввод своего значения с клавиатуры (например, 5500);
- начальное значение: **4000 Кбит/с**;
- применяется к новой трансляции, независимо от разрешения и FPS.

## Сохранение качества

После подключения LiveKit и успешного запуска захвата плагин сразу атомарно записывает **разрешение, режим FPS и битрейт** в `%APPDATA%\TS3Client\plugins\ts3stream\stream-settings.json`. При следующем открытии окна запуска, в том числе после перезапуска TeamSpeak, значения читаются из файла. «60 FPS» и «Авто» сохраняются как разные режимы. Отмена выбора или ошибка запуска не заменяют последние сохранённые настройки.

Разрешения: **720p (1280×720), 900p (1600×900), 1080p (1920×1080), 1440p (2560×1440)**. Пропорции сохраняются, небольшие окна не увеличиваются. Для первого запуска без файла: **1080p, 30 FPS, 4000 Кбит/с**. Повреждённые/недопустимые поля заменяются безопасными начальными значениями. При невозможности записи стрим продолжает работать, ошибка попадает в `diag.log`.

Выбранное окно/экран и звук не сохраняются. Файл настроек пользователя не включается в установочный пакет и не перезаписывается обновлением плагина.

Это верхний предел кодировщика, а не обязательная постоянная скорость и не ограничение суммарного сетевого трафика. WebRTC может снижать скорость при ухудшении канала. Аудио, служебные пакеты и повторные передачи добавляют трафик сверх видеобитрейта; краткие всплески тоже возможны.

Выбор проходит через `CaptureSource` и состояние захвата в `TrackPublishOptions.video_encoding`. Для значения по умолчанию в `diag.log` записываются `bitrate_kbps=4000` и `maxBitrate=4000000`. Явный выбор в окне имеет приоритет над диагностической переменной `TS3STREAM_MAX_BITRATE`; она сохраняется для тестовых программ без явного выбора.

Сервер и установщик для этого выбора не меняются. Выпущенный ранее плагин 0.3.9 ещё не содержит это поле. Само снижение битрейта не гарантирует устранение всех потерь; результаты сетевых тестов следует оценивать отдельно от проверки интерфейса.
