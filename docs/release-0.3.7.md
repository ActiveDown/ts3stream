# TS3Stream 0.3.7

- На Windows без `GraphicsCaptureSession.IsBorderRequired` (включая обычную Windows 10) захват **монитора** автоматически использует DXGI Desktop Duplication без жёлтой рамки. Захват отдельного окна остаётся WGC и на Windows 10 может иметь рамку.
- DXGI выбирает адаптер захватываемого монитора, обрабатывает поворот и отдельный курсор, пытается восстановить захват после потери доступа. При ошибке не переключается на другой монитор или WGC с рамкой.
- Громкость просмотра: **0–125%**, исходный уровень по умолчанию — 100%. Усиленные пики ограничиваются диапазоном PCM16 без переполнения. Mute и переключение fullscreen сохраняют выбранный уровень; голоса TeamSpeak и исходящий звук не меняются.
- Для кодировщика задан `MaintainFramerate`: при нехватке ресурсов/полосы приоритет имеет плавность, а не разрешение. Кадры подаются не чаще выбранного FPS, в ожидании отправки сохраняется только самый свежий кадр.

## Ограничения

Дополнительный сетевой буфер на две секунды **не добавлен**: поставляемый LiveKit C++ SDK 1.13.1 не предоставляет настройки целевой задержки WebRTC jitter buffer. Увеличение очереди уже декодированных кадров не восстанавливает отброшенные WebRTC кадры и требует сотен мегабайт. Изменения подачи кадров не являются обещанием отсутствия пауз при перегрузке кодировщика, потере пакетов или недостаточной скорости сети.

Уточнение последующей проверки: у LiveKit Server есть `room.playout_delay`. Эксперимент с текущим клиентом подтвердил задержку видео, но не синхронную задержку аудиоколбэков; результаты и ограничения описаны в [0.3.8](release-0.3.8.md).

## Проверка

Регрессионные тесты: `desktop_frame_test`, `desktop_capture_test`, `viewer_controls_test`, `video_send_queue_test`. Существующий `wgc_resize_test` проверяет сохранение захвата отдельного окна при изменении размеров. DXGI можно проверить напрямую и на Windows 11; автоматическое переключение и отсутствие рамки в клиенте требуют отдельной проверки на Windows 10.

Локально прошли сборка MSVC x64, перечисленные тесты, `source_picker_test`, `viewer_autohide_test`, `live_stream_menu_test`. DXGI проверен на трёх мониторах с разным DPI, включая вертикальный 1440×2560. На отдельном локальном LiveKit прошли `stream_ended_test` в режимах `static` и `resize` (поздний зритель, восемь размеров до 2560×1440, завершение просмотра). Проверки не моделируют ограниченную сеть и не подтверждают устранение всех зависаний при резкой смене сцены.
