# Серверная часть

Go-сервис управления стримами + конфигурация LiveKit для Linux.

## Планируемые эндпоинты

- `POST /api/token` — выдача JWT для публикации/просмотра.
- `GET /api/live` — активные стримы.
- `GET /api/health` — здоровье сервиса.

## Планируемые функции

- Проверка UID через TS3 ServerQuery.
- Комната = канал TS3 (с префиксом сервера).
- Установка/снятие `client_icon_id` (красная иконка).
- Подпись JWT ключами LiveKit.
- Конфиг в YAML, секреты через переменные окружения.
